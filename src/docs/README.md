# 개발자 단어 사전 이용 안내

**개발자 단어 사전은 개발 공부 중 만난 낯선 용어를 검색하고, 쉬운 설명과 사용 예시, 코드 예시로 뜻을 알아보는 서비스입니다.**

강의를 듣다가 “컴포넌트가 뭐지?”라는 생각이 들면 단어를 찾아 짧은 설명을 읽고, 실제로 어떻게 쓰이는지 확인할 수 있습니다. 웹 개발을 처음 배우는 사람이나 이미 배운 용어를 다시 확인하고 싶은 사람에게 유용합니다.

이 문서는 현재 구현된 화면과 동작을 기준으로 작성했습니다. 이용자는 단어를 찾아 읽을 수 있고, 새 단어 등록 화면을 통해 사전에 내용을 추가할 수도 있습니다.

## 처음 방문했다면 이렇게 이용하세요

React를 공부하다가 **컴포넌트(Component)**라는 단어가 궁금해졌다고 가정해 보겠습니다.

1. 홈 화면의 **“궁금한 개발 단어를 검색해 보세요”** 입력창에 `컴포넌트`를 입력합니다.
2. 필요한 경우 **React** 카테고리를 눌러 해당 분야의 결과로 좁힙니다.
3. 검색 결과에서 **컴포넌트** 카드의 짧은 설명을 읽습니다.
4. **“자세히 보기 →”**를 누르면 사용 예시와 코드 사용 예시를 볼 수 있습니다.
5. 다른 단어가 궁금하면 **“← 단어 목록으로”**를 눌러 홈으로 돌아갑니다.

단어 이름을 정확히 몰라도 설명에 들어갈 만한 표현으로 검색할 수 있습니다. 예를 들어 `재사용`을 입력하면 쉬운 설명에 이 표현이 포함된 단어도 나옵니다.

## 어떤 화면이 있나요?

아래 주소는 서비스의 기본 주소 뒤에 붙는 경로입니다. 예를 들어 로컬 개발 서버가 기본 포트로 실행 중이라면 홈은 `http://localhost:3000/`입니다.

| 화면 | 주소 | 할 수 있는 일 |
| --- | --- | --- |
| 단어 목록 | `/` | 전체 단어 보기, 검색, 카테고리 선택, 상세 화면으로 이동 |
| 단어 상세 | `/words/주소-이름` | 단어의 뜻, 사용 상황, 등록된 코드 예시 확인 |
| 새 단어 등록 | `/admin` | 단어와 설명, 사용 예시, 코드 예시를 입력해 사전에 추가 |

컴포넌트의 상세 주소는 `/words/component`, API의 상세 주소는 `/words/api`입니다. 상세 주소를 복사해 두면 나중에 같은 단어를 바로 열 수 있습니다.

현재 홈에는 새 단어 등록 화면으로 가는 메뉴가 없으므로, 등록하려면 주소창에 서비스 주소 뒤 `/admin`을 직접 입력합니다.

## 검색하고 분야별로 살펴보기

홈에서는 단어마다 **카테고리, 단어 이름, 쉬운 설명, 자세히 보기 링크**가 카드로 표시됩니다. 목록은 단어 이름을 기준으로 정렬되며, 검색 결과 개수도 함께 나타납니다.

### 검색은 이렇게 동작합니다

- **입력하는 즉시 결과가 바뀝니다.** 검색 버튼을 누르거나 Enter 키를 누를 필요가 없습니다.
- **단어 이름과 쉬운 설명에서 찾습니다.** 사용 예시, 코드 내용, 상세 주소의 이름은 검색 대상에 포함되지 않습니다.
- **입력한 글자가 일부만 포함되어도 결과에 나옵니다.** 예를 들어 `컴포넌트`로 검색하면 `서버 컴포넌트`도 찾을 수 있습니다.
- **영어 대소문자와 검색어 앞뒤 공백을 구분하지 않습니다.** `API`, `api`, 앞뒤에 공백을 붙인 ` api `는 같은 결과를 보여줍니다.
- **검색어와 카테고리가 동시에 적용됩니다.** React를 선택한 상태라면 검색어와 일치하는 React 단어만 표시됩니다.

모든 단어를 다시 보려면 검색어를 지우고 **전체**를 선택하세요. 목록 옆의 **“N개의 단어”**는 현재 검색어와 카테고리 조건에 맞는 개수입니다.

### 어떤 분야의 단어를 찾을 수 있나요?

| 카테고리 | 다루는 내용 | 등록된 단어 예시 |
| --- | --- | --- |
| 웹 | 웹 통신, JavaScript 기초, 개발 도구, Next.js 관련 개념 | API, 변수, 함수, HTTP, Git, Node.js, App Router |
| React | 화면 구성, 상태 관리, React 문법과 동작 | 컴포넌트, JSX, Hook, useState, useEffect, 렌더링 |
| 데이터 | 데이터 저장, 조회, 데이터베이스 구조 | 데이터베이스, MongoDB, SQL, 스키마, 기본 키, 외래 키 |

2026년 9월 11일 확인한 초기 데이터(Seed Data)는 **67개**이며, 웹 37개·React 9개·데이터 21개로 구성되어 있습니다. 실제 서비스에 보이는 개수는 이후 등록된 데이터에 따라 달라집니다.

**전체**는 모든 카테고리를 모아 보여줍니다. 등록 화면에서는 **기타**도 선택할 수 있지만, 홈에는 기타 전용 버튼이 없습니다. 기타로 등록된 단어는 전체에서 찾아볼 수 있습니다.

## 상세 화면에서 단어 이해하기

상세 화면은 **뜻 → 사용 상황 → 코드** 순서로 읽으면 이해하기 쉽습니다.

| 표시 항목 | 무엇을 알 수 있나요? | 컴포넌트 단어의 예 |
| --- | --- | --- |
| 카테고리와 단어 이름 | 어떤 분야의 개념인지 | React / 컴포넌트 |
| 쉬운 설명 | 단어의 핵심 의미 | 화면을 구성하는 재사용 가능한 작은 UI 조각 |
| 이렇게 사용해요 | 실제로 사용하는 상황 | 버튼과 검색창을 각각 컴포넌트로 만들 수 있습니다. |
| 코드 사용 예시 | 코드에서는 어떻게 표현하는지 | 인사 문구를 화면에 보여주는 `Welcome` 함수 예시 |
| 코드 종류 | 예시에 사용된 언어나 환경 | JSX |

코드 종류는 예시를 읽는 데 참고하는 표시입니다. 코드 예시가 등록되지 않은 단어는 코드 영역이 나타나지 않습니다.

현재 코드 영역은 내용을 읽는 용도이며, 코드를 직접 실행하거나 결과를 확인하는 기능은 없습니다. 긴 코드는 코드 영역을 가로로 스크롤해 확인할 수 있습니다.

## 새 단어를 등록하려면

`/admin`의 **새 단어 등록** 화면에서 아래 내용을 입력합니다. 등록한 단어는 서비스의 단어 목록에 추가되므로 다른 이용자도 볼 수 있습니다.

| 입력 항목 | 작성 방법 | 입력 예시 |
| --- | --- | --- |
| 단어 | 화면에 보여줄 이름 | 콘솔 로그 |
| 주소 이름(Slug) | 상세 주소에 사용할 고유한 이름 | `console-log` |
| 카테고리 | 웹, React, 데이터, 기타 중 선택 | 웹 |
| 쉬운 설명 | 처음 배우는 사람도 이해할 수 있도록 뜻을 설명 | 프로그램의 값을 콘솔에 출력해 확인하는 방법 |
| 사용 예시 | 이 개념을 사용하는 구체적인 상황 | 변수에 어떤 값이 들어 있는지 확인할 때 사용합니다. |
| 코드 종류 | JavaScript, JSX, Node.js, MongoDB, Terminal 중 선택 | JavaScript |
| 코드 사용 예시 | 설명과 연결되는 코드 작성 | `console.log("안녕하세요");` |

카테고리는 처음에 **웹**, 코드 종류는 **JavaScript**로 선택되어 있습니다. 나머지 입력 칸은 모두 채워야 하며, 새 단어를 등록할 때는 **코드 사용 예시도 필수**입니다.

### 주소 이름은 무엇인가요?

주소 이름(Slug)은 단어의 상세 페이지를 구별하는 이름입니다. 예를 들어 `console-log`로 등록하면 상세 주소는 `/words/console-log`가 됩니다.

- 영문, 숫자, 하이픈(`-`)을 사용할 수 있습니다.
- 영문 대문자는 저장할 때 소문자로 바뀌고, 앞뒤 공백은 제거됩니다.
- 한글, 중간 공백, 하이픈 이외의 특수문자는 사용할 수 없습니다.
- 이미 등록된 주소 이름은 다시 사용할 수 없습니다. 중복 여부는 단어의 표시 이름이 아니라 **주소 이름**을 기준으로 확인합니다.

### 등록 버튼을 누르면

1. **단어 등록**을 누릅니다. 처리 중에는 버튼이 **“등록 중...”**으로 바뀌고 중복 제출을 막기 위해 잠시 비활성화됩니다.
2. 성공하면 **“새 단어가 등록되었습니다.”**라는 메시지가 표시되고 입력 칸이 초기화됩니다.
3. 자동으로 상세 화면으로 이동하지는 않습니다. **“← 단어 목록으로”**를 눌러 등록한 단어를 검색하거나, 정한 상세 주소로 직접 접속해 확인합니다.

등록에 실패하면 안내 메시지를 보고 내용을 수정한 뒤 다시 시도할 수 있습니다.

## 이용 중 원하는 결과가 나오지 않을 때

| 화면이나 메시지 | 가능한 이유 | 이렇게 확인하세요 |
| --- | --- | --- |
| 단어를 불러오는 중입니다... | 목록을 가져오는 중 | 잠시 기다립니다. 계속 표시되면 새로고침해 다시 시도합니다. |
| 검색 결과가 없습니다. 다른 단어를 검색해 보세요. | 검색어와 카테고리에 맞는 단어가 없거나, 아직 등록된 단어가 없음 | 전체를 선택하고 검색어를 지웁니다. 단어 이름이나 쉬운 설명에 들어갈 만한 표현으로 다시 찾습니다. |
| 단어 데이터를 불러오지 못했습니다. | 서버나 데이터 연결에 문제가 생김 | 새로고침 후 다시 확인합니다. 계속 실패하면 사이트를 관리하는 사람에게 상황을 알립니다. |
| 모든 항목을 입력해 주세요. | 필요한 내용이 비었거나 공백만 입력됨 | 코드 사용 예시를 포함해 빠진 내용이 없는지 확인합니다. 빈 입력 칸은 브라우저가 먼저 안내할 수도 있습니다. |
| 주소 이름은 영문, 숫자, 하이픈만 사용할 수 있습니다. | 주소 이름에 허용되지 않는 글자가 있음 | `console-log`처럼 영문, 숫자, 하이픈으로 수정합니다. |
| 이미 같은 주소 이름을 사용하는 단어가 있습니다. | 동일한 주소 이름이 이미 사용 중 | 다른 주소 이름을 정합니다. |
| 단어 등록에 실패했습니다. | 서버나 저장 과정에서 문제가 생김 | 입력 내용을 확인한 후 다시 시도합니다. 계속 실패하면 사이트를 관리하는 사람에게 알립니다. |
| 상세 주소에서 404 화면이 나타남 | 그 주소 이름으로 등록된 단어가 없음 | 홈으로 돌아가 단어를 검색하고, 카드의 자세히 보기 링크로 다시 들어갑니다. |

## 현재 이용 범위에서 알아둘 점

- **회원가입이나 로그인 화면은 없습니다.** 단어 조회와 `/admin` 등록 화면에 로그인 없이 접근할 수 있으며, 현재 등록 요청에도 관리자 권한을 확인하는 절차가 없습니다.
- **단어 조회와 새 단어 등록을 제공합니다.** 등록된 단어를 수정하거나 삭제하는 화면은 아직 없습니다.
- **검색 조건을 주소에 저장하지 않습니다.** 홈을 새로고침하거나 상세 화면의 “단어 목록으로” 링크로 돌아오면 검색어와 카테고리가 초기화됩니다. 특정 단어를 다시 보려면 상세 주소를 보관하세요.
- **개인별 학습 관리 기능은 없습니다.** 즐겨찾기, 최근 본 단어, 학습 진도, 퀴즈, 댓글 기능은 현재 제공하지 않습니다.
- **단어 목록이 실시간으로 갱신되지는 않습니다.** 다른 이용자가 추가한 단어가 보이지 않으면 홈을 새로고침해 최신 목록을 확인하세요.
